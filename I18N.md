# HitIT Internationalization (i18n)

This project fully supports multiple languages! 🌍

## Current Languages

- **English (en)** - Default language
- **Deutsch (de)** - German translation (complete)

All UI elements, game modes, and dynamic content are fully translated in both languages.

## How it Works

The i18n system uses:
- `src/i18n/i18n.js` - Core translation engine
- `src/i18n/locales/en.js` - English translations
- `src/i18n/locales/de.js` - German translations

### For Users

1. Open the **Settings** menu (hamburger icon ☰)
2. Select your preferred **Language** from the dropdown
3. The interface will update immediately

Your language preference is saved in browser storage.

## For Developers

### Adding a New Language

1. **Create a new locale file** in `src/i18n/locales/`:

```javascript
// src/i18n/locales/es.js (example for Spanish)
export default {
  title: 'Canción aleatoria de Jellyfin',
  start: {
    welcome: 'Bienvenido a HitIT',
    // ... add all keys from en.js
  },
  // ... complete all sections
};
```

2. **Import and register** in `index.html`:

```html
<script type="module">
  import { initI18n } from './src/i18n/i18n.js';
  import en from './src/i18n/locales/en.js';
  import de from './src/i18n/locales/de.js';
  import es from './src/i18n/locales/es.js'; // Add new import
  
  initI18n({ en, de, es }); // Register language
</script>
```

3. **Add to language selector** in `index.html`:

```html
<select id="settingLanguage">
  <option value="en">English</option>
  <option value="de">Deutsch</option>
  <option value="es">Español</option> <!-- Add option -->
</select>
```

4. **Update display name** in `src/i18n/i18n.js`:

```javascript
function getLanguageDisplayName(langCode) {
  const displayNames = {
    'en': 'English',
    'de': 'Deutsch',
    'es': 'Español' // Add display name
  };
  return displayNames[langCode] || langCode;
}
```

### Using Translations in Code

#### In HTML (static content):

```html
<!-- Translate text content -->
<h2 data-i18n="start.welcome">Welcome to HitIT</h2>

<!-- Translate attributes (like placeholder) -->
<input data-i18n-attr="placeholder" placeholder="e.g., Rock">
```

#### In JavaScript:

```javascript
import { t } from './src/i18n/i18n.js';

// Simple translation
alert(t('messages.noSongFound'));

// With parameters (interpolation)
alert(t('messages.playerWins', { name: 'Alice', size: 10 }));
// Result: "Player Alice wins with a deck of 10 cards!"
```

### Translation Key Structure

```
title                    - Page title
start.*                  - Start screen
mpSetup.*               - Multiplayer setup
guessSetup.*            - Guess-the-Year setup
menu.*                  - Navigation menu
settings.*              - Settings panel
choose.*                - Random playback mode
guess.*                 - Guess-the-Year mode
multiplayer.*           - Multiplayer mode
common.*                - Common UI elements (OK, Cancel, etc.)
messages.*              - User messages, alerts, notifications
```

### String Interpolation

Use `{variableName}` in translation strings:

```javascript
// en.js
messages: {
  playerWins: 'Player {name} wins with {size} cards!'
}

// Usage
t('messages.playerWins', { name: 'Bob', size: 15 })
// → "Player Bob wins with 15 cards!"
```

### Language Change Events

Listen to language changes:

```javascript
window.addEventListener('languagechange', (e) => {
  console.log('Language changed to:', e.detail.language);
  // Re-render dynamic content if needed
});
```

5. Check browser console for missing translation warnings

## Translation Guidelines

- **Keep keys consistent** across all language files
- **Use descriptive keys**: `menu.settings` not `m.s`
- **Maintain context**: Group related translations
- **Test placeholders**: Ensure `{variables}` work in all languages
- **Check formatting**: Some languages need different word order
- **Preserve special chars**: Keep emojis, symbols (✓, ●, etc.)

## Common Pitfalls

❌ **Don't hardcode strings:**
```javascript
alert('Fehler beim Laden'); // BAD
```

✅ **Use translation keys:**
```javascript
alert(t('messages.loadingError')); // GOOD
```

❌ **Don't forget to update ALL locale files:**
- If you add a key to `en.js`, add it to `de.js` too!

✅ **Keep locale files in sync:**
- Check all languages have the same key structure
